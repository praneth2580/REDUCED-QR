# RQR

This project is a demonstration of various data compression algorithms, implemented in React and TypeScript.

## Portal

You can access the live portal here: [https://praneth2580.github.io/REDUCED-QR](https://praneth2580.github.io/REDUCED-QR)

## Installation

To run this project locally, you need to have Node.js and npm installed. Then, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/praneth2580/REDUCED-QR.git
   ```
2. Navigate to the project directory:
   ```bash
   cd REDUCED-QR
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

## Usage

To start the development server, run the following command:

```bash
npm run dev
```

This will start the application in development mode and open it in your default browser at `http://localhost:3000`.

To build the application for production, run:

```bash
npm run build
```

This will create a `dist` folder with the optimized production build.

To deploy the application to GitHub Pages, run:

```bash
npm run deploy
```
